## Registro de ejecución

OpenCode debe añadir una entrada después de cada fase con:

- Fecha y hora.
- Archivos modificados.
- Pruebas ejecutadas.
- Resultado.
- Errores encontrados.
- Decisión tomada.
- Commit creado.

No borrar entradas anteriores. Si una prueba falla, registrar el fallo antes de cambiar de estrategia.
