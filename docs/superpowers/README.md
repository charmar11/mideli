# Diseños y planes con fecha

`specs/` contiene decisiones de diseño tomadas antes de implementar; `plans/`
contiene planes de trabajo. Son evidencia de intención y razonamiento, no una
confirmación de que el código o la producción tengan ya ese comportamiento.

Para conocer el estado vigente, empieza por el
[índice del proyecto](../README.md), revisa el código y confirma el estado
remoto si la tarea depende de él. Conserva estos archivos como historial.
