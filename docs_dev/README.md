# Bitácoras de desarrollo

Esta carpeta conserva investigaciones, hallazgos y planes de tareas con fecha.
No es un registro automático del estado actual: una tarea pudo implementarse
después, quedar incompleta o cambiar de diseño.

Para empezar una tarea nueva, lee [AGENTS.md](../AGENTS.md), el
[índice vigente](../docs/README.md) y el
[proceso de trabajo](../docs/WORKFLOW.md). Consulta aquí únicamente la bitácora
del tema que investigas y contrástala con el código y el estado remoto.

La iniciativa multinegocio original está en
[food-garden-multi-business/](food-garden-multi-business/README.md). Su
`Estado actual` fue escrito antes de activar Just Dipping y es histórico.
